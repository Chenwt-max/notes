# 使用指南

## 课程和本地视频

“我的课程”新建课程。点击名称旁编辑图标原位改名；在课程整理页排序、改名或把课时移动到另一门课。在本地视频页批量填写完整本机路径，每行一个；路径含空格或中文无需转义，复制时外层引号可以保留。网络 URL、文件夹和不存在的文件会提示错误。已导入路径不会重复登记。

新建提取时选择整课或时间范围。重复处理已有范围先弹窗确认，现有结果保留。暂停后等待状态变为已暂停再继续。线程、课程并发、GPU 并发在设置中保存；GPU 安全并发受实际显存限制。快速模式没有固定等待，听课优先会主动留余量。长时间满负载时的温度由设备散热与电源状态共同决定。

## 笔记、来源和播放

整课的字幕和课件筛选就绪后才开始整理。整理、复核和最终分章都完成后公开笔记；中间工作稿保留，失败不会清空素材。笔记目录按完整知识主题组织。拖动笔记与课件之间的分隔条，双击复位；键盘方向键也能调整。默认每组展示信息较完整的代表页，补充画面可以展开查看；无法安全合并的不同公式或动画状态继续保留。

点击图片打开原图，放大检查细节；“来源”可以回到对应视频时间。视频可选倍速、全屏或隐藏旁边的笔记。新任务的文字和公式由多模态 API 对照原图整理，生成的公式还会经过本地渲染检查。旧任务已有公式候选及手动修订继续保留。

## 六角色助手

左键打开或收起对话并切换当前角色姿态，右键打开角色轮盘；轮盘没有可见角色名字。拖动角色或对话窗，调整大小条和对话窗尺寸。可打开或关闭同角色定时姿态切换。当前是静态多姿态图集切换，没有声称连续骨骼动画。

笔记中选中文字后提问，助手结合上下文解释。实际调用模型以 API 设置为准，角色只改变外观与语气。外观切换、拖动和定时动作不调用 API；问答费用独立于笔记整理上限。

未配置单价时，回答标记“本次费用未知”；有单价时按用量计算，极小正费用显示为小于 ¥0.0001。费用未知不代表免费。

## 异常恢复与费用

任务概览显示整理、复核和分章状态。坏响应、未唯一定位的修订保留旧响应和原稿；明确点击重试并确认后才创建新尝试。同一确认重复提交只产生一次尝试。预算不足先调整设置或处理原任务额度，已有账本不清零。每份笔记创建时固定其现金上限，之后修改默认值只影响新任务。

接口超时不代表免费或没有生成。核对供应商账单后填写实际费用：未收费填 0，确认后显式重试。缓存命中的已完成响应不再次收费。账单只记应用可观察的 usage/配置单价或保守预留，以供应商实际结算为准。

## 导出和删除

“导出学习资料”可下载精简课件包或完整学习资料包，解压后打开 HTML，图片、公式和来源索引可离线查看。离线包不含原视频，因此来源时间可查，视频播放需保留本机原视频与程序。

点击垃圾箱图标删除课程或笔记；运行中的任务先停止再清理。原视频、共享模型与费用账本保留。删除失败会提示并可重试，不会把未完成清理的结果假装成成功。存储设置可清理无引用的生成缓存，不按文件日期盲删必要补充状态。


## 已有PPT或PDF

在“新建提取任务”的“课件来源”中选择“使用已有 PPT / PDF”，填写本机课件完整路径。视频仅用于字幕与回放，课件直接渲染原文档页面，不执行视频中的课件检测。默认仍可从视频提取。

支持 PDF、PPTX 和 PPT。PDF 无需 Office；PPT/PPTX 需要本机 PowerPoint 或 LibreOffice，没有时可先另存为 PDF。原文件不改动，任务内保存副本，删除任务只清理副本。页面没有视频时间戳时不显示虚构回放点。

## 课件筛选与图片整理

本地图像算法先合并明显重复，视频路线用 YOLOX 辅助排除教师遮挡；PaddleOCR-VL-1.6 为页面分组提供内容线索，不再强制执行 RapidOCR 或单独提取本地公式。已有课件直接使用原页参与筛选。

请配置支持图片输入的 API 模型，例如 deepseek-flash。整理时发送字幕与高清课件原图，直接读取文字、公式，并在同一次调用中判断完全重复、非课件与动画终态。正文、复核、最终分章累计受每份笔记额度限制，默认 ¥1；问答独立计费。图片也计入输入费用，超过预算时保留本地素材并提示调整，不静默漏页。

默认课件栏显示精选结果；仅在替代目标明确且保留完整内容时隐藏中间或重复页。判断缺失、冲突或不确定时保留。点击“查看全部来源”可查看被隐藏的原页；API 判断不会删除来源位图。无文字层的扫描页也会发送原图，PDF文字提取顺序不作为公式真值。

旧任务继续使用原检查点与原识别路线；新建任务采用上述图片整理路线，不会刷新旧任务后自动重新收费。
