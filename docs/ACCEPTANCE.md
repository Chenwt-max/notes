## 修复并有回归证据的问题

1. 用独立 Python home 重建三套运行时，避免复制 venv 对本机 Python 的路径依赖；内置工具和离线渲染资源。
2. 启动器核对目录/版本归属，增加令牌控制的检查点停止与重启；缺失工具状态明确、端口冲突不误杀。真实 CMD 入口在继承 Restricted 进程策略下通过启动/停止，仅使用进程级参数，不修改系统执行策略。
3. Windows 跨账户密钥解密失败转为重新填写提示，既有资料可读。
4. 新笔记固定按份计费，默认 ¥1；整理、复核、分章累计预留，修改默认值不重置历史任务。预算不足可以单独修改暂停任务的上限。
5. 完整正文不因附属修订字段损坏丢失；未知 usage 保留保守费用，不让坏计数字段摧毁有效正文。
6. 失败重试必须明确确认，幂等请求只产生一次尝试；旧响应保留，未知账目先核账；重试继承上次问题反馈，不保留失效的复核确定标记。
7. 中文目录下 OpenCV XML 文件加载改为内存读取同一模型；原生 DyNET 路径不支持中文的问题通过独立启动器 UTF-8 activeCodePage 清单修复，未更换模型或中文识别算法。
8. API 复核强化严格不等式、边界反例、秩条件和必要/充分条件的检查。验收发现的一处必要条件错误经反馈重试修正；不会据此宣称模型能自动发现所有逻辑错误。
9. 模型未下载时，首次首页仍引导准备，但刷新已有笔记或直接进入设置不会强制跳走；新建课程等待目录刷新后导航，避免短暂出现“课程不存在”。三个独立启动回归已加入 CI。
10. 助手的屏幕边界排除滚动条宽度，并在可用宽度变化时重新定位，避免缩小窗口后产生横向溢出。回归先复现旧行为，再通过修复后的组件测试和真实页面检查。
11. 打包前先检查三套运行时和工具是否齐全，避免构建目录缺失时静默生成不完整便携包。源码归档按当前白名单过滤历史暂存文件；排除私有 QA 和配置，更新前端构建时清除旧哈希资源。
12. 接口基础地址按 URL 主机和协议解析，拒绝含账号段、缺失主机、畸形端口及不可拼接的查询/片段。13项隔离回归及真实页面保存/刷新验证通过，没有向测试地址发出请求。
13. 阅读页入场动效仅作用于标题，避免固定助手、轮盘及对话框被父容器临时变换带偏；默认动效下连续进入4次，屏幕边缘工具均未溢出。
14. 未设置单价的问答明确显示费用未知；小于 ¥0.0001 的正费用不再舍入为零。问答仍不设费用上限。组件回归先复现再修复，并由本机HTTP夹具补测未知单价、已知单价和坏响应。
15. 复核修订统一在原始正文中定位，再从后向前应用互不重叠的改动；拒绝重叠或依赖前一次替换结果的修订。旧付费响应在本地重新检查，不重新请求或计费，既有原文和诊断保留。
16. 整理、复核、分章和问答共同覆盖空 choices、畸形消息及 usage 容器。有效正文不会因 usage 结构异常丢失；非文本 content 不强制转成正文，无法确认收费的失败保留预留并等待核账，不自动重试。52项接口响应回归在修复前复现29项失败，修复后全部通过。
17. 自制低帧率课程的结尾指定时间晚于最后一帧时，恢复该帧原始像素并保留实际时间戳；超出视频范围仍报错。旧实现的空缓冲崩溃已复现，3项专用回归及相关画面测试通过；正常字幕和画面识别策略不变。
18. 带来源编号的独立识别排版说明移入元数据，保留邻近公式、学习内容和代码。新增裸写LaTeX检查，未包数学分隔符的响应不直接标记完成；保留原响应、原文和已计费用，明确重试前不再次请求。
19. 聚合后的章节标题不再重复同名内部标题，独立子主题及全部正文和来源保持。复核提示增加数值代回定义与符号一致性要求；自制例题仍需两次明确验收反馈才完成修订，不据此宣称自动复核必定正确。
20. KaTeX固定升级至0.18.2并统一传递依赖，修复其在已有原型污染条件下继承trust设置的问题；两项只渲染字符串的安全回归不执行不可信HTML。独立候选与主目录回归、真实34数学节点及三档宽度通过，便携检查器和导出资源同步。npm audit从4条同源关联low记录降至0条，授权清单同步；见[维护者公告](https://github.com/KaTeX/KaTeX/security/advisories/GHSA-238p-pmpm-9mq7)。
21. 核心OpenCV约束与主要求统一为4.14.0.94，CI及源码安装显式使用约束文件。新建隔离Python环境按相同命令安装，pip check无损坏依赖、317项回归通过，有1条TestClient兼容接口弃用警告；共享宿主系统，不作为干净Windows验收。
