# notes 1.0.0-rc.1

首个公开测试版，面向 Windows 桌面浏览器使用。

- 批量导入本机视频路径，按课程管理、原位改名、移动课时和删除任务。
- 课件来源可选视频自动提取或已有PDF/PPTX/PPT；直接使用原页，跳过视频课件检测，全部文档页可追溯。
- 本地 Qwen3-ASR-1.7B 字幕与时间对齐，本地图像去重、YOLOX 遮挡辅助与 PaddleOCR-VL-1.6 课件筛选；整理时由多模态 API 读取字幕和高清原图，视频与音频不上传。
- 完整素材就绪后整理、复核与语义分章，默认每份笔记总预算 ¥1，可在设置修改；选文问答独立计费。
- 高清课件来源、互补画面、可调 PPT 分栏、笔记搜索和视频倍速回看。
- 六角色全部36种主姿态、玻璃轮盘、大小调整、拖动和定时切换。
- 三套独立 Python 运行时、FFmpeg/ffprobe、Node 与离线公式资源，支持中文和空格路径；模型首次另行下载并校验。

## 下载

便携版约6.55 GiB，分为4个分卷。下载全部分卷以及 `release-manifest.json`、`merge-release.ps1`、`合并并解压.cmd` 到同一目录，双击合并入口。解压后运行 `notes.cmd`。首次准备需另下载约8.1 GiB模型，CPU/GPU可在设置选择。

源码开发环境和使用方式见项目 README。公开示例为自制短课；私人测试课程、个人配置、密钥和缓存不随交付分发。主要模型权重首次另行下载；运行时依赖自带的轻量 RapidOCR/Silero 资源随依赖分发并校验，模型权重不进入源码包。

## 验证范围

发布前已完成317项后端回归、前端构建和组件交互、中文路径迁移及本机CPU/GPU短样本验证。随后补充已有课件输入：10项新文档用例、合计48项关联回归、选择与原页浏览组件交互通过；PPTX和PPT的本机转换均验证隐藏页保留和原文件不变。随后按用户选择改为本地筛选与 API 读原图：130项定向关联回归、组件交互与构建通过，未重新运行私人整课。1次自制4页真实API检查耗时7.09秒、费用¥0.010556：矩阵及残差成稿正确，重复页和非课件页可隐藏；中间页仍保守保留，不宣称终态全召回。旧317项属于先前冻结基线，不替代新路线全场景验收。

独立干净Windows、真实课堂字幕人工逐字金标，以及全部页面异常状态的实机操作仍待验收。远端CI结果见仓库Actions。识别和AI整理仍可能出错，应结合来源阅读，详见验收记录与已知限制。
