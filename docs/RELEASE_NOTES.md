# notes 1.0.0-rc.1

首个公开测试版，面向 Windows 桌面浏览器使用。

- 批量导入本机视频路径，按课程管理、原位改名、移动课时和删除任务。
- 本地 Qwen3-ASR-1.7B 字幕与时间对齐，PaddleOCR-VL-1.6 课件文字和公式识别；视频与完整课件无需上传大模型。
- 完整素材就绪后整理、复核与语义分章，默认每份笔记总预算 ¥1，可在设置修改；选文问答独立计费。
- 高清课件来源、互补画面、可调 PPT 分栏、笔记搜索和视频倍速回看。
- 六角色全部36种主姿态、玻璃轮盘、大小调整、拖动和定时切换。
- 三套独立 Python 运行时、FFmpeg/ffprobe、Node 与离线公式资源，支持中文和空格路径；模型首次另行下载并校验。

## 下载

便携版约6.55 GiB，分为4个分卷。下载全部分卷以及 `release-manifest.json`、`merge-release.ps1`、`合并并解压.cmd` 到同一目录，双击合并入口。解压后运行 `notes.cmd`。首次准备需另下载约8.1 GiB模型，CPU/GPU可在设置选择。

源码开发环境和使用方式见项目 README。公开示例为自制短课；私人测试课程、个人配置、密钥、模型权重和缓存不随交付分发。

## 验证范围

发布前已完成317项后端回归、前端构建和组件交互、中文路径迁移及本机CPU/GPU短样本验证。本次发布整理仅调整公开文档，不更换模型或识别策略，不重新进行整课运行。

独立干净Windows、真实课堂字幕人工逐字金标，以及全部页面异常状态的实机操作仍待验收。远端CI结果见仓库Actions。识别和AI整理仍可能出错，应结合来源阅读，详见验收记录与已知限制。
