# 源码维护更新 · 2026-10-24

本页描述当前源码增量。便携附件尚未公开，旧候选中的运行时和冻结验收不能冒充新源码已打包。代码继续MIT，六角色36种主姿态及回退图片保留。

## 处理与复核

- Qwen3-ASR-1.7B和正常字幕识别保持。视频先图像去重和遮挡辅助，再由PaddleOCR-VL-1.6对代表页提供筛选线索；原页、互补状态和来源不因减少推理次数而丢失。原文档仍保留全部页序。
- API原图与阅读原图恢复指定时刻已经显示的帧，共用缓存版本，避免借用下一页内容。
- 新图片路线的DeepSeek复核使用低强度思考、流式接收和独立输出上限。思考计入费用和token，调用前完整预留；不完整响应保留原正文与待核账预留，不自动重发。

## 页面和稳定性

- 相同正文复用Markdown和公式排版。后台自动刷新按请求串行进行；隐藏页面暂停，返回即时刷新。模型准备页仅在运行中使用较快刷新频率。
- 课件侧栏控制区留出更多图片空间，原图有加载/失败状态，适应窗口保留完整画面和底部操作。
- 设置标题大于说明，开关有清晰的开/关状态、整行点击和键盘反馈。配置、存储、目录、视频库区分加载、空数据与失败，可明确重试。
- 笔记、目录、视频库、任务列表的旧读取不能覆盖较新结果；切换课程后的旧错误不会串入。进入笔记避免无必要的重复资料读取，任务完成时仍刷新旧阶段资料。
- 笔记刷新失败保留已加载正文；重新读取仅访问本机资料，不等于重新整理，不产生付费模型调用。

## 可复现验证与边界

自动回归使用自制输入、模拟HTTP响应和本机临时目录；不附私人课程、笔记、密钥、配置或私有验收原始数据。接口乱序测试先在旧实现复现，再校验旧响应、旧错误、列表刷新和恢复行为。真实浏览器设置布局与自制恢复示例另行核对。

独立干净Windows、真实课堂人工听写金标、完整异常矩阵仍待验收。界面及有限样本通过不代表所有课程零错误。CI结果以仓库Actions对应提交为准。

### 此次源码候选的本机结果

在单独的白名单源码目录中，357项后端回归零失败/错误/跳过，23个前端回归入口、TypeScript及生产构建通过。后端使用已有锁定依赖环境，前端重新执行npm ci；同一Windows宿主，不作为干净系统验收。测试没有改写候选中的458个源文件。源码目录之外的测试输出不随项目分发。

真实浏览器检查另覆盖7个设置页的35组尺寸，以及自制HTTP失败/重试界面。读取乱序与错误恢复是受控响应场景，不是模型识别准确率证据。远端CI以Actions对应新提交的实际结果为准。

### 便携测试的模型前置条件

便携包首次使用需要完成模型准备。三个任务创建业务测试现在显式模拟“模型已就绪”，避免由未下载模型拦截而无法核验各自的目录边界、重复提醒和模型配置；另有独立测试分别验证模型未就绪时拒绝创建、就绪时允许创建。程序中的模型准备检查保持不变。
