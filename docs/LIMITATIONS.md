# 已知限制

- 语音、遮挡课件和密集公式可能识别错误；语法检查与 AI 复核不能代替原始来源，也不保证所有课程零错误。
- 8 GiB GPU 以安全串行的重模型槽为主；其他应用占用显存时会等待。低于 7 GiB 的设备不加载当前重模型，需用 CPU。CPU 速度与内存占用需按实机评估。
- 来源原本模糊时，高清恢复只取原视频分辨率，不虚构超分辨率细节。
- 便携包面向 Windows 10 1903 及以上 x64，需要可写磁盘；GPU 需要正常 NVIDIA 驱动。首次准备需要网络，之后本地识别可断网运行；API 整理和问答仍需要对应服务连接。
- 外观角色是静态姿态切换，不是连续肢体动画。角色不改变实际 API 服务商。
- 外部接口价格、可用性与账单以供应商为准。用户手动核账必须以已结束请求的真实账单填写，不能把未知请求当作免费。
- 正式发布前所有未完成的实机与干净环境检查必须如实列在验收表；不能把浏览器夹具检查当成实际用户页面操作。

- 本轮锁定前端依赖的 npm audit 结果为0条已知漏洞；KaTeX固定为0.18.2并统一其传递依赖，源码、网页、便携检查器及导出资源一致。后续发布仍需重新审计，渲染保持不信任输入并禁止原始HTML。

- 已有课件输入直接读取文字层与常见Office Math结构；PDF不能保证重建公式，图片公式、扫描页及不支持的Office公式由 API 直接读取原页，仍可能误读。PPT/PPTX渲染依赖本机PowerPoint或LibreOffice，便携包不捆绑Office；LibreOffice路径尚未在本机实测。原文档无时间信息时不声称精准视频同步。

- 课件终态和重复判断仍可能保守漏合并；信息不确定时保留原图。不能宣称所有动画答案必然识别。大课件集受每份费用和单请求大小限制，超限会明确中止，保留来源供调整后继续。
- 新的原图整理路线会上传课件图片和字幕；本地提取阶段不上传，视频和音频均不上传。
