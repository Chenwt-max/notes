# 自制公开演示与可复现短课

## 界面演示

打开 index.html。全部文字、公式和课件由开发者自行编写，仅用于展示程序布局、导航和交互，不是课程识别结果或准确率评测。接口返回固定自制夹具，不联网、不调用付费接口。六角色使用程序内同一套已授权素材。

演示视频为程序生成的测试图案，不含教师、真实课程或语音。运行中的实际提取、付费 API、删除磁盘成果和模型下载应在正式应用中核验，演示不冒充这些真实行为。

## 可处理的自制短课

`selfmade-lesson.webm` 是另外一段 2 分钟的原始教学视频：三张自行编写的 1920×1080 幻灯片，加上本机 Windows 中文语音合成的24句话。内容覆盖矩阵维数、正规方程、秩条件、最小二乘参数和残差；不包含任何私有课程。可以把视频路径导入 notes，正常执行字幕、课件、公式和笔记处理。

`lesson-script.json` 是讲稿，`lesson-reference.srt` 与 `lesson-reference.json` 是生成音频时记录的参考文本和时间，`lesson-slide-1.png` 至 `lesson-slide-3.png` 是原始幻灯片。这些参考文件独立于识别输出，不能把它们当作程序已经识别成功的结果。合成声音、静止画面和清晰排版比教室录制简单，测试结果不代表真实课程准确率，也不能替代人工听写金标。

在装有 Windows 中文桌面语音（Microsoft Huihui）、微软雅黑、Cambria 和程序依赖的开发环境，可重新生成：

```powershell
.venv\Scripts\python.exe docs/demo/make-lesson.py --ffmpeg "完整的FFmpeg路径"
```

生成器不使用网络语音服务。中间 WAV 放在程序 `cache/public-demo-build` 内，发布只包含原视频、原幻灯片和参考文本；不会捆绑系统字体。生成器用有理数计算核验示例参数和残差，避免把参考答案建立在识别或 API 输出上。

## 实际处理结果

[processed-lesson.zip](processed-lesson.zip) 是这段自制视频的真实程序输出，解压后打开 `notes.html`。包含字幕、识别课件、公式候选及经过API整理和反馈复核的笔记，共110个文件，离线渲染资源已附带。未手工替换成稿正文；数值符号和裸写公式问题经程序明确重试修订，失败响应与费用记录留在本地私有验收目录。

实际得到24段字幕、3张1920×1080来源和1个知识章节。按NFKC、忽略标点/空白并统一英文大小写比较371个参考字符，差2个“唯／为”替换，合成语音CER为0.54%。原始9个公式候选中仍有1个语法错误；不能把候选和最后笔记混为一谈。完整指标和限制见 [selfmade-result.json](selfmade-result.json)。

这次自制示例共10次实际接口调用、按配置单价计¥0.150366，包含失败试验。两次启用思考模式均在6000输出token内截断，没有返回成稿，因此未保留启用思考模式的程序改动。有限样本与人工反馈修订不能证明未来笔记零错误。
