# 准确性与性能记录

## 真实样本范围

使用私有课程的三个 3 分钟片段，合计 9 分钟，覆盖线性模型、矩阵、最小二乘、几何解释、屏幕/镜头切换、教师遮挡、重复画面、正态分布和似然公式。私有输入、输出、标注与截图均不随项目发布。

来源文件身份保持不变，142 段字幕全部有分配，192 次画面来源映射保持完整。保留 96 幅图片、14 内容组；必要补充状态可展开，不能把全部保留画面视为独立 PPT 页。

## 样本精度边界

固定 20 个字幕时间落点、20 个页面/板书状态与20个较复杂公式候选进行核对。字幕落点仅完成时间范围与来源定位检查，没有人工逐字听写 CER 金标，不能声称逐字准确率。

20 项较复杂公式抽查中：15 项主要数学结构与来源相符（部分有排版差异），2 项存在局部内容/条件省略，1 项数组格式字符串错误而不能渲染，2 项图中下标不够清晰，未判为精确匹配。原始候选不是最终成稿，异常有原图保留；最终成稿的主要公式、矩阵维数、正负号和条件另行对照来源核验。

成稿抽查发现一处把统计经验建议写成矩阵可逆必要条件的错误。泛化复核第一次没有完全解决；带具体反例的验收反馈通过程序重试送入 API 后，改成列满秩与 N≥M+1 的正确关系。修订由程序保存，原文与已付费响应保留。这个过程说明 AI 复核可能漏错，不能把“复核完成”当作数学正确证明。

20 个画面抽查保留了教师遮挡的互补状态、板书增量、投影与整屏切换。一些自动裁剪边缘靠近标题；可回看整帧，不能据此宣称所有自动区域都无遗漏。高清恢复使用原视频像素，不生成不存在的细节。

主要耗时在文档/公式识别，而不是固定等待。保留当前模型与识别设置，没有为发布而降低图像精度、截短公式或更换模型。

## 资源与费用

外部采样观察到 GPU 显存最高 **7111 / 8188 MiB**，GPU 温度最高 **66°C**。进程树 RSS 采样最高 3829.9 MiB；内存采样在任务启动后 189.7 秒才开始，因此不是完整冷启动内存峰值。没有获得可信的 CPU 温度，不用 GPU 温度代替。

上述私有样本及前期助手验收真实 API 13 次，按设置单价及 usage 核算 **¥0.176800**。后续自制示例另用10次、¥0.150366；本轮合计 **23次、¥0.327166**，低于本轮 ¥1。问答和笔记账目独立，历史账本未清零。实际供应商结算以其账单为准。

原始计时、显存、温度与内存 CSV 保存在开发者本地的私有验收目录；没有在产品界面加入实验计时器。

助手问答实测还暴露了模型可能混淆“线性方程无精确解”与“最小二乘无解”的风险；第一轮有长度截断提示，后续追问纠正了这一关系。这里验证了请求、历史上下文、缓存和独立记账功能，不把问答输出当作已证明的数学结论。

## 可公开复现的合成短课

[自制短课](demo/README.md)有24句讲稿、3张原始课件和独立参考字幕，视频120秒。真实提取产生24段字幕，3张高清来源、9个公式候选，最终1个知识章节。371个规范化参考字符有2个“唯／为”替换，CER 0.54%，24个参考语句中点均落在识别语音范围内。规范化只做NFKC、英文大小写及标点/空白过滤，不替换术语或数字。合成声音和清晰静止画面比课堂简单，此结果不补齐真实课堂人工金标门槛。

首次运行因低帧率结尾取帧中断，字幕检查点保留；修复后沿用原任务恢复。两次活动运行分别151.48秒、124.03秒，合计275.50秒；从首次启动到恢复完成的449.62秒包含开发修复等待，不能当作连续处理速度。后续API复核试验另计，不含在这些时间中。外部采样显存最高6704 / 8188 MiB、GPU温度55°C；此轮便携核心环境未提供RSS采样，不编造内存峰值。

分项累计：字幕阶段129.03秒，语音识别30.50秒、音频解码0.88秒、时间对齐1.12秒、模型加载16.74秒、检查点写入0.07秒。文档/公式阶段83.15秒，其中模型加载38.31秒、识别26.83秒。阶段包含子项，不能相加；未计入的进程启动等时间不补估。快速模式节流调用记录0.03 / 0.04秒为计时开销，没有固定休息。

最终逐项核对矩阵维数、正规方程、秩条件、参数、残差正负号和投影对象。初稿及首轮泛化复核仍漏了残差符号矛盾，明确反馈才修正；随后裸写LaTeX经第二次反馈修复，未手工替换正文。原始9个公式候选有1个语法错误，最终阅读页34个数学节点、0个KaTeX错误。1366/1920/2560三档宽度无横向溢出，来源大图实际恢复到1920×1080。

启用DeepSeek思考模式的两次受限试验都在6000输出token内截断且无最终正文，因此撤回该试验改动。程序仍使用原有非思考请求模式，新增数值代入要求、精确定位、正文清理和未包裹LaTeX的失败拦截。不能把“API复核完成”当作数学正确证明。原始失败响应和累计账本保留。
